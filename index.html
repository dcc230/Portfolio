04 / Project

FYREAssignments

This project is a general collection of assignments from an introductory engineering class focused on sensing and embedded systems. The work combines programming, circuit building, and sensor-based experimentation to explore how devices respond to real-world inputs such as light, moisture, and user interaction.

The goal is not just to write code, but to understand how a system behaves in practice: how sensors collect data, how microcontrollers interpret it, and how small design choices shape the outcome. The assignments emphasize iteration, hands-on testing, and using software and hardware together to create responsive, functional systems.
